Entry for make.fun's "One Word From Your Ex" bounty: a program that writes exactly one word — the word an ex would use to describe you — to `/output/entry.txt`. The word is **Unmatched**: a dating-app verb used as a person-descriptor. The ex did not just leave; they revoked the match itself with one tap. The funniest, most painfully honest single word wins, judged pairwise by an AI judge.

## Run it

```sh
node main.ts
```

This writes the one-word entry to `/output/entry.txt`. For local testing, pass an output directory as the first argument:

```sh
node main.ts /tmp/one-word-ex-test
cat /tmp/one-word-ex-test/entry.txt
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). No dependencies to install.
